# ☕ 카페이야기 (Cafe Story) - RBAC 접근 제어 미니실습

본 프로젝트는 Flask + MySQL(Docker) + PyJWT + Tailwind CSS 기반으로 구현된 **역할 기반 접근 제어(Role-Based Access Control, RBAC)** 웹 애플리케이션입니다.

---

## 📌 1. 권한 등급 체계 (RBAC Matrix)

| 권한 레벨 (`role_level`) | 등급 명칭 | 역할 설명 | 접근 가능 페이지 및 API |
| :---: | :---: | :--- | :--- |
| **Level 0** | **일반회원** | **최초 회원가입 시 기본 부여**되는 등급 | 메인 홈(`/`), 게시글 조회 및 작성 |
| **Level 1** | **골드회원** | 카페 우수 회원 및 **중간 관리자** 등급 | 메인 홈(`/`), **골드 라운지(`/gold`)**, 골드 혜택 API |
| **Level 2** | **관리자** | 시스템 총괄 운영자 | **모든 페이지**, **관리자 센터(`/admin`)**, 회원 등급 수정, 회원 삭제 |

---

## 🚀 2. 구현 요구사항 충족 내역

| 번호 | 요구사항 | 구현 내용 및 증빙 |
| :---: | :--- | :--- |
| **1** | **헤더**: 골드등급 링크, 관리자링크, 로그인 유저명 & 권한 표기 | 상단 고정 헤더에 `골드 라운지(Lv.1)`, `관리자 센터(Lv.2)` 링크 제공. 로그인 시 `닉네임(아이디)` 및 등급 뱃지(`일반회원 Lv.0` / `골드회원 Lv.1` / `관리자 Lv.2`) 실시간 표기 |
| **2** | **페이지 구성**: 골드, 관리자 페이지 화면 간단 구성 | • `/gold`: 골드 회원 및 중간관리자 전용 VIP 라운지 (원두 할인 쿠폰, 바리스타 레시피, 안건 투표)<br>• `/admin`: 회원 관리 통계 카드 및 전체 회원 조회/수정/삭제 대시보드 |
| **3** | **회원가입**: 일반 유저(Lv.0)로 가입 | `POST /api/auth/register` 호출 시 `role_level` 기본값 `0` 강제 주입 및 자동 로그인 지원 |
| **4** | **접근 제어(인가)**: 일반: 0, 골드: 1, 관리자: 2 | `@role_required(min_level, is_page)` 데코레이터를 구현하여 페이지 요청 시 403 HTML 예외화면 렌더링, REST API 요청 시 403 JSON 응답 반환 |
| **5** | **관리자 페이지**: 회원정보 조회, 수정, 삭제 기능 | • 조회: `GET /api/admin/users` (회원 목록 및 통계)<br>• 등급 수정: `PUT /api/admin/users/<id>/role` (드롭다운으로 0, 1, 2 즉시 변경)<br>• 삭제: `DELETE /api/admin/users/<id>` (회원 영구 삭제) |
| **6** | **예외 화면 출력**: 해당 등급이 아닐 경우 예외화면 출력 | 권한 미달 접근 시 **HTTP 403 Forbidden 예외 화면(`error_role.html`)** 출력. 요청 페이지 URL, 필요 등급, 현재 내 등급 비교 박스 및 홈/로그인 안내 제공 |
| **7** | **+a 기능 (편의성 & 완성도)** | • 원클릭 빠른 테스트 로그인 버튼 (관리자, 골드, 일반 계정 즉시 전환)<br>• 쿠키 + JWT Bearer 헤더 하이브리드 인증 지원 (브라우저 주소창 직접 이동 및 API 호출 완벽 지원)<br>• 카페이야기 게시글 CRUD 및 카테고리별 글쓰기 |
