# 005. 등급별 접근제어 (user · gold · admin)

작성일: 2026-09-10 · 대상: `_7_board_test`

---

## 0. 한 줄 요약

등급은 **계단식**이다. `user(1) < gold(2) < admin(3)` — 필요 등급보다 **같거나 높으면** 통과한다.
그래서 `admin` 은 골드 화면도 볼 수 있고, 등급마다 계정을 새로 만들 필요가 없다.

---

## 1. 화면에서 막는 것과 서버에서 막는 것

메뉴를 숨기는 것만으로는 **막은 게 아니다.** 주소창에 API 를 직접 치면 그대로 열린다.
그래서 두 겹으로 막는다.

| 계층 | 어디서 | 무엇을 | 목적 |
|---|---|---|---|
| 화면 | `templates/gold.html` 의 JS | `/api/auth/me` 로 등급 확인 → 예외 화면 | 사용자 경험 |
| 서버 | `controllers/gold_controller.py` | `@role_required('gold')` → 403 | **실제 차단** |

### 직접 확인해 보기

일반 회원으로 로그인한 뒤 주소창에 `/api/gold/posts` 를 쳐 보면 이렇게 나온다.

```json
{"msg": "골드 등급 이상만 이용할 수 있습니다.",
 "required_role": "gold", "current_role": "user"}
```

화면(F12)을 아무리 조작해도 **데이터는 서버가 주지 않는다.** 이게 핵심이다.

## 3. 등급을 새로 추가하려면

`models/user.py` 의 **표 두 개에만** 추가하면 된다.

```python
ROLE_LEVEL = {'user': 1, 'gold': 2, 'admin': 3}      # 여기에 넣고
ROLE_LABEL = {'user': '일반', 'gold': '골드', 'admin': '관리자'}   # 여기에 이름을
```

예를 들어 `silver` 를 `user` 와 `gold` 사이에 넣고 싶다면 값을 재배치한다.

```python
ROLE_LEVEL = {'user': 1, 'silver': 2, 'gold': 3, 'admin': 4}
ROLE_LABEL = {'user': '일반', 'silver': '실버', 'gold': '골드', 'admin': '관리자'}
```

`VALID_ROLES` 는 `ROLE_LEVEL` 에서 자동으로 만들어지므로 관리자 페이지의 검증도 같이 따라온다.
(화면 select 의 `<option>` 과 `_denied.html` 의 `ROLE_LABEL` 은 따로 손봐야 한다.)

## 4. 핵심 코드

### 판정 — `controllers/rbac.py`

```python
def role_required(required):
  def decorator(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
      user = current_user()
      if user is None:
        return jsonify({...}), 401          # 누구인지 모른다
      if role_level(user.role) < role_level(required):
        return jsonify({...}), 403          # 알지만 등급이 모자라다
      request.current_user = user
      return fn(*args, **kwargs)
    return wrapper
  return decorator
```

**401 과 403 은 다르다.**

| 코드 | 뜻 | 화면 |
|---|---|---|
| `401` | 로그인 안 함 | "로그인이 필요합니다" + 로그인하러 가기 버튼 |
| `403` | 로그인했지만 등급 부족 | "골드 등급 이상만 볼 수 있습니다" |

`role_level()` 은 모르는 값을 **0** 으로 떨어뜨린다. 오타나 이상한 값이 들어와도
권한이 생기는 게 아니라 **없는 쪽으로** 실패한다(fail-closed).

### 사용 — `controllers/gold_controller.py`

```python
@gold_bp.route('/posts', methods=['GET'])
@role_required('gold')
def gold_posts():
  rows = Post.query.filter_by(category='골드').order_by(Post.id.desc()).limit(20).all()
  return jsonify({'count': len(rows), 'posts': [p.to_dict() for p in rows]})
```

### 화면 — `templates/gold.html`

토큰은 `localStorage` 에 있어서 페이지를 열 때 **서버로 자동 전송되지 않는다.**
그래서 화면 JS 가 직접 물어본다.

```javascript
if (!token()) { showDenied({ required: 'gold', current: null }); return; }

const me = await (await fetch('/api/auth/me', { headers: authH() })).json();
if (!me.is_gold) { showDenied({ required: 'gold', current: me.role }); return; }

showProtected();
loadGoldPosts();
```

## 6. 관리자 페이지에서 등급 주고 뺏기

`/admin` → **권한 부여 (인가)**

| 항목 | 값 |
|---|---|
| 대상 아이디 | 등급을 줄 회원 |
| 등급 | `🏅 gold` / `🔐 admin` / `user` |
| 사유 | 감사 기록에 남는다(선택) |

**회수**는 회원 목록의 빨간 `회수` 버튼이다. 등급이 무엇이든 **`user` 로 되돌린다.**
`gold` 든 `admin` 이든 같은 버튼으로 처리된다.

### 부여·회수 기록이 남는다

`users` 표의 `role_granted_by` · `role_granted_at` · `role_reason` 에 **누가·언제·왜** 가 남는다.
`admin` 회수는 `security_events` 에도 감사기록(`source='privilege-guard'`)이 쌓여 대시보드에 뜬다.

## 7. 골드 게시글 만들기

골드 화면의 목록은 **카테고리가 `골드` 인 게시글**을 보여준다.

1. 게시판(`/`)에서 로그인 후 글쓰기
2. 카테고리를 **🏅 골드 (골드 등급 전용)** 로 선택
3. 등록하면 `/gold` 화면에 나타난다

> 게시글이 하나도 없으면 골드 화면에 "아직 골드 전용 게시글이 없습니다" 가 뜬다. 정상이다.

## 9. 로그인 토큰 키가 통일됐다

전에는 화면마다 다른 키를 써서 **게시판에서 로그인해도 관리자 페이지는 로그아웃 상태**로 보였다.

| | 전 | 후 |
|---|---|---|
| `index.html` | `token` / `username` | `token` / `username` |
| `admin.html` | `board_token` / `board_user` | `token` / `username` |
| `gold.html` | — | `token` / `username` |

이제 한 번 로그인하면 모든 화면에서 유지된다.

## 10. 자주 나는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| 헤더에 골드 링크가 안 보임 | 브라우저가 옛 화면을 캐시 | `Ctrl+F5` 로 새로고침 |
| 골드를 줬는데 계속 막힘 | 토큰에 옛 정보가 남음 | **로그아웃 후 다시 로그인** |
| 골드 화면이 계속 "확인하는 중" | `/api/auth/me` 실패 | F12 → Network 탭에서 응답 확인 |
| 골드 글이 목록에 없음 | 카테고리가 `골드` 가 아님 | 글 수정에서 카테고리 변경 |
| 관리자 페이지가 401 | 그 계정이 `admin` 이 아님 | 다른 admin 계정으로 부여 |

> **등급을 바꾼 뒤에는 다시 로그인해야 한다.**
> 등급 자체는 매 요청마다 DB 에서 다시 읽지만, 화면이 기억하는 `role` 은 로그인 시점 값이다.
